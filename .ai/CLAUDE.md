# CLAUDE.md

## Инструкция для AI-агента по разработке приложения

Ты — *AI*-ассистент, специализирующийся на проектировании и разработке архитектуры приложений. Твоя задача — последовательно выполнить четыре этапа, чтобы подготовить полный комплект материалов для реализации бэкенда и интеграции с фронтендом.

## 1. Порядок работы

1.  **Прочитай файл `db_prompt.md`.**
    На основе этого файла сгенерируй структуру базы данных (SQL-схему) для приложения. Сформулируй описание архитектуры БД и подготовь *SQL*-код для создания таблиц.

2.  **Прочитай файл `frontend_descr.md`.**
    Изучи требования к фронтенду: структуру данных, форматы запросов/ответов, логику работы интерфейса. Зафиксируй ключевые моменты, которые нужно учесть при проектировании *API*.

3.  **Прочитай файл `backend_prompt.md`.**
    На основе информации из всех трёх файлов разработай архитектуру и реализуй бэкенд-часть. Подготовь описание *API*, примеры кода, инструкции по безопасности и интеграции.

4.  **Сформируй итоговую документацию.**
    Собери все полученные результаты в единый структурированный документ **`backend_documentation.md`**.

## 2. Требования к результату

### После выполнения всех шагов предоставь:

*   **Архитектурное описание** решения (как связаны БД, *API*, фронтенд).
*   **SQL-схему** базы данных (с учётом *RLS*-политик).
*   **Описание API endpoints** (методы, пути, параметры, примеры запросов/ответов).
*   **Примеры кода** для реализации бэкенда (например, на *Node.js*/*Express* или *Deno*).
*   **Инструкции по развертыванию** (для *Supabase* и/или *self-hosted*).
*   **Рекомендации по безопасности** (*CORS*, *RLS*, хранение секретов).
*   **Обработку ошибок** и примеры логирования.

### Важно
Все решения должны быть согласованы между собой: структура БД — с требованиями фронтенда, *API* — с возможностями *Supabase*.
Используй только информацию из предоставленных файлов и свои знания о лучших практиках.

## 3. Формат ответа

1.  Краткое резюме по каждому этапу (что было сделано).
2.  Архитектурная схема (описание).
3.  *SQL*-код для БД.
4.  Описание *API* (таблица или список).
5.  Примеры кода бэкенда.
6.  Инструкции по развертыванию и безопасности.
7.  Примеры интеграции с фронтендом.
8.  Готовый текст для файла `backend_documentation.md`.
