# Промпт для AI-агента: разработка Frontend-приложения «Budget Track Web»

## 1. Контекст и цель
Разработать современное веб-приложение для учёта личного бюджета. Пользователь должен иметь возможность добавлять доходы и расходы, категоризировать их и просматривать статистику.

## 2. Технологический стек
- **Фреймворк:** React (с TypeScript).
- **Сборка:** Vite.
- **Стилизация:** Tailwind CSS.
- **Маршрутизация:** React Router v6.
- **Тестирование:** Jest, React Testing Library.
- **Линтинг:** ESLint, Prettier.

## 3. Основные функции (минимум)
1. Добавление расходов и доходов с выбором категории.
2. Просмотр списка всех операций с фильтрацией по дате/категории.
3. Визуализация статистики (например, круговая диаграмма расходов по категориям).

## 13. Управление категориями доходов и расходов

### Контекст
Категории расходов и доходов захардкожены в `src/utils/helpers.ts` в виде констант `expenseCategories` и `incomeCategories`. Категории используются в компонентах `CategorySelect`, `Statistics`, `Dashboard` и в API-слое. Цвета категорий также определены статически.

### Цель
Реализовать полный CRUD для категорий: пользователь может добавлять, удалять и редактировать собственные категории расходов и доходов. Категории должны сохраняться в localStorage и загружаться при старте приложения. Предустановленные (дефолтные) категории нельзя удалять, но можно редактировать их название.

### Функциональные требования

1. **Добавление категории**
   - Пользователь указывает: название (обязательное, уникальное в рамках типа), тип (расход/доход), цвет (выбор из предустановленной палитры).
   - Новая категория сразу появляется в селектах `CategorySelect` и в фильтрах на Dashboard.
   - Валидация: пустое название, дубликат названия, название длиннее 30 символов.

2. **Удаление категории**
   - Дефолтные категории нельзя удалить (кнопка неактивна или скрыта).
   - Пользовательские категории можно удалить.
   - Если существуют транзакции с удаляемой категорией — показать предупреждение и предложить перевести их на другую категорию того же типа или удалить вместе с категорией.
   - Удаление подтверждается через модальное окно.

3. **Редактирование категории**
   - Можно изменить название и цвет любой категории (включая дефолтные).
   - Изменение названия дефолтной категории влияет только на отображение, значение (value) остаётся прежним.
   - Для пользовательских категорий можно изменить и название, и цвет.

4. **Хранение**
   - Категории хранятся в localStorage (ключ `budget_track_categories`).
   - При первом запуске — инициализация дефолтными категориями.
   - Структура: `{ expense: CategoryInfo[], income: CategoryInfo[] }` с дополнительным полем `isDefault: boolean`.

5. **UI для управления**
   - Новая страница `/categories` с маршрутами в `routes.tsx`.
   - Список категорий с группировкой по типу (расходы/доходы).
   - Каждая категория — карточка с цветным индикатором, названием, кнопками «Редактировать» и «Удалить».
   - Кнопка «Добавить категорию» открывает модальное окно с формой.
   - Ссылка на страницу категорий в `Header.tsx`.

### Структура данных

Обновить `CategoryInfo` в `types.ts`:
```typescript
export interface CategoryInfo {
  value: string;          // уникальный идентификатор (slug)
  label: string;          // отображаемое название
  color: string;          // HEX-цвет
  isDefault: boolean;     // true для предустановленных
}
```
